# رِواق — تقارير ومستندات Word دون خدمات مدفوعة

يعمل التطبيق دون مفاتيح اشتراك أو اتصال بخدمة توليد سحابية. توجد طريقتان واضحتان:

* **تحليل المصادر دون نموذج:** جاهز فور التثبيت؛ يختار مقاطع من ملفاتك أو نصوصك بحسب قربها من الموضوع، وينظمها مع مراجعها في تقرير قابل للتحرير والتصدير. المقاطع مقتبسة من المصدر؛ هذا الوضع لا يؤلّف شرحاً جديداً ولا يترجم النص ولا يضمن الوصول إلى عدد الصفحات المستهدف.
* **صياغة بنموذج محلي مجاني:** اختيارية، باستخدام نموذج GGUF عبر `llama-cpp-python` داخل عملية Python نفسها. لا خادم API ولا مفتاح. تتيح الكتابة من الموضوع أو المصادر، وتعتمد الجودة والسرعة على الجهاز والنموذج. النموذج الصغير قد يخطئ، ولا يعادل نماذج الخدمات الكبيرة.

البرنامج ومساراته لا تفرض رسوم توليد. التشغيل على جهازك يستخدم موارده؛ أي تكلفة استضافة يختارها المستخدم منفصلة عن التطبيق.

## التشغيل

يتطلب Python 3.12:

```bash
cd /workspace/Teaching-App  # أو مجلد المشروع على جهازك
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m streamlit run app.py
```

اختر **المصادر المرفقة فقط**، واكتب الموضوع وأرفق PDF نصياً أو DOCX أو TXT/MD بترميز UTF-8 أو ألصق نصاً. ثم أعدّ التقرير وحرّره ونزّله. زر **فتح نموذج تنسيق** يعرض عيّنة ثابتة مميزة بوضوح.

حدود المصادر: خمسة ملفات (10 ميغابايت للملف)، خمسة روابط، 90 ألف حرف إجمالاً، وPDF حتى 400 صفحة. المصادر المصوّرة تحتاج OCR خارجياً. لا تُحفظ الملفات والتقارير تلقائياً على القرص؛ نزّل عملك قبل إنهاء الجلسة.

## تثبيت النموذج المحلي الاختياري

المسار الافتراضي يستخدم النموذج الرسمي `Qwen/Qwen2.5-1.5B-Instruct-GGUF` بتكميم `Q4_K_M`، والمتاح بترخيص Apache 2.0؛ راجع بطاقة النموذج وترخيصه قبل التوزيع. يتطلب نحو 1–2 غيغابايت لتنزيل الملف، وذاكرة إضافية للتشغيل؛ يُنصح بـ 8 غيغابايت RAM على الأقل. لا يحتاج بطاقة رسوميات، وقد يستغرق التقرير عدة دقائق أو أكثر على CPU.

على Linux ثبّت أدوات البناء C/C++ إن لم تكن موجودة، ثم من مجلد المشروع:

```bash
# GCC/G++ بديلان عن أي متغير CC/CXX يشير إلى مترجم غير متاح.
CC=gcc CXX=g++ CMAKE_ARGS='-DGGML_NATIVE=OFF -DGGML_CUDA=OFF' CMAKE_BUILD_PARALLEL_LEVEL=2 .venv/bin/python -m pip install -r requirements-local.txt
.venv/bin/python scripts/setup_local_model.py
```

يتحقق برنامج التنزيل من SHA-256 بحسب بيانات الناشر الرسمية، ولا يعطّل TLS أو يستبدل ملفاً موجوداً مختلفاً. يُحفظ النموذج في `models/` المستبعد من Git. يمكن بدلاً من التنزيل توفير ملف GGUF موثوق في المسار المحدد أو ضبط `RIWAQ_MODEL_PATH` إلى ملف محلي موثوق. يستخدم التطبيق قالب المحادثة المرفق بالنموذج. بعد تثبيت النموذج اضغط **تحديث النماذج المحلية**، واختره من القائمة ثم اضغط **تفعيل النموذج المختار**. لا تظهر رسالة النجاح إلا بعد قبول محرك التشغيل للملف.

سياق النموذج 8192 token؛ يرفض التطبيق المصادر التي لا تترك مجالاً كافياً للجواب بدلاً من حذفها بصمت. التقارير المطولة جداً قد تحتاج إلى تقسيم الموضوع وتحرير المحتوى. تُرفض الإجابة المبتورة بدلاً من عرضها مكتملة.

**حالة البيئة الحالية:** تحليل المصادر والتصدير مختبران. الوصول إلى سجل Hugging Face محجوب حالياً من بروكسي البيئة، لذلك النموذج غير منزّل ولم يُتحقق من توليد حقيقي به. تعليمات البناء والتنزيل اختيارية ولا تعيق وضع تحليل المصادر.

## اكتشاف النماذج الموجودة وتفعيلها

في الشريط الجانبي يظهر زر **تحديث النماذج المحلية**. يجري فحص أولي تلقائي عند فتح الصفحة؛ والزر يعيد الفحص بعد إضافة الملفات أو حذفها، دون تنزيل نماذج أو تحديث أوزانها من الإنترنت.

1. يفحص التطبيق `models/` ومجلدات LM Studio الشائعة (`~/.lmstudio/models` و`~/.cache/lm-studio/models`) وHugging Face (`~/.cache/huggingface/hub`) ومجلدات Ollama الشائعة.
2. يراعي `RIWAQ_MODEL_PATH` و`HF_HOME` و`HF_HUB_CACHE` و`OLLAMA_MODELS`. يمكن إدخال مجلد آخر في **مجلد نماذج إضافي** ثم الضغط على زر التحديث.
3. يعرض أسماء ملفات GGUF وأحجامها ومسار النموذج المختار. في Ollama يقرأ بيانات النماذج لربط الاسم بملف GGUF المحلي؛ لا يحتاج تشغيل خادم Ollama أو الاتصال بأي API.
4. اختر نموذجاً واضغط **تفعيل النموذج المختار**. يجرب محرك llama.cpp تحميله، وبعد النجاح يختار التطبيق وضع الصياغة المحلية لهذه الجلسة. مجرد العثور على الملف لا يعني توافق معماريته أو كفاية ذاكرة الجهاز؛ يظهر سبب الفشل عند تعذّر التفعيل.
5. عند تبديل النموذج يحرر المحرك أوزان النموذج السابق قبل تحميل الجديد، ويمنع التبديل أثناء إنشاء تقرير. يحتفظ كل مستخدم باختيار جلسته؛ ويُحمّل الاختيار المطلوب عند توليد تقريره. إذا استُبدل ملف النموذج أو حُذف، يطلب التطبيق إعادة الفحص والتفعيل.

**الفحص يتم على الجهاز الذي يشغّل Python.** إذا شغّلت التطبيق على حاسوبك يمكنه اكتشاف نماذج ذلك الحاسوب. نسخة السحابة تفحص ملفات الخادم فقط، ولا تستطيع الوصول إلى قرص جهازك الشخصي عبر المتصفح. الصيغ المدعومة هي GGUF؛ ملفات Transformers أو ONNX تحتاج إلى مسار تشغيل مختلف. الفحص يقتصر على المجلدات المذكورة أو المجلد الإضافي، ويعرض تنبيهاً عند بلوغ حدود الملفات/العمق أو تعذّر القراءة.

## الإنترنت الاختياري

تحليل الملفات والنصوص والتصدير يعمل دون إنترنت بعد تثبيت الاعتماديات. خيار البحث يستخدم صفحة DuckDuckGo العامة دون خدمة بحث مدفوعة أو مفتاح؛ قد يُحجب أو يطلب تحققاً، وعندها أضف مصادر مباشرة. يُرسل إليه موضوع البحث فقط، لا محتوى الملفات. اختيار المصادر المرفقة فقط لا يجري بحثاً تلقائياً.

في بيئة شبكة مقيّدة:

* تنزيل النموذج: `huggingface.co`، وقد تحتاج إلى السماح بنطاق التنزيل الرسمي الذي تعيده الخدمة عند إعادة التوجيه، مثل `cas-bridge.xethub.hf.co`.
* البحث الاختياري: `html.duckduckgo.com`، إضافة إلى نطاقات المصادر الناتجة التي تختار السماح بها.
* الروابط المباشرة: نطاقات المصادر نفسها. يتحقق التطبيق من أن عناوينها عامة ويرفض الشبكات الخاصة. إذا لم يتوفر DNS محلي، يستخدم `dns.google` عبر HTTPS للتحقق من اسم النطاق؛ لا يرسل إليه محتوى ملفاتك.

لا يقرأ التطبيق متغيرات مفاتيح المزوّد القديم ولا يستعملها. يمكن حذف متطلب `RIWAQ_API_KEY` القديم من إعدادات البيئة؛ أداة حفظ المسودة لا تدعم حذف متطلبات الأسرار. لا حاجة لإدخال أي قيمة فيه.

## التصدير والتحقق

Word يشمل غلافاً وفهرس عناوين وجداول وملاحظات وترويسات وترقيم صفحات، مع RTL للعربية وLTR للإنجليزية. الفهرس جدول عناوين دون أرقام صفحات تلقائية؛ يحدد Word أرقام التذييل عند الفتح. راجع الاقتباسات والمخرجات قبل الاستخدام الأكاديمي.

```bash
.venv/bin/python -m pip check
.venv/bin/python -m pytest -q
```

تشمل الاختبارات إنشاء تقرير دون نموذج أو شبكة، وعدم إجراء اتصالات توليد خارجية، والتحرير والتصدير، وقراءة الملفات، وفحوص المصادر العامة، وتكامل النموذج المحلي باستجابات محاكاة. مساحة التعلّم السابقة باقية في قائمة الصفحات.

## توثيق مساحة التعلّم السابقة

# رِواق — Teaching App

تطبيق ويب عربي متجاوب للتعلّم من كتب PDF، دون API مدفوع أو مفتاح سري. يتضمن كتاباً تجريبياً أصلياً من ثلاث صفحات يمكن استخدامه فور التشغيل.

## التشغيل على الحاسوب

يتطلب Python 3.12. من مجلد المشروع:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m streamlit run app.py
```

على Windows استخدم `.venv\Scripts\activate` للتفعيل. افتح المنفذ 8501 في متصفح الحاسوب بعد تشغيل الخادم.

## الاستخدام من الهاتف

شغّل التطبيق على الحاسوب وصِل الهاتف بالشبكة المحلية نفسها، ثم افتح `http://<عنوان-IP-الحاسوب>:8501`. اسمح بالاتصال على المنفذ 8501 في جدار حماية الشبكة الخاصة عند الحاجة. لا يتطلب الهاتف تثبيت Python؛ يجب أن يبقى الخادم يعمل.

للوصول عبر الإنترنت يلزم خادم يدعم Streamlit/WebSocket وHTTPS. لا ينشئ المشروع رابط استضافة عاماً تلقائياً. التطبيق مصمم لمتعلم واحد؛ لا توجد حسابات أو عزل بين المستخدمين. استخدم بوابة دخول موثوقة قبل إتاحة كتبك الخاصة عبر الإنترنت.

## Docker (بديل)

```bash
docker compose up --build -d
```

يحفظ volume المسمى `riwaq-data` المكتبة والتقدم بين إعادة التشغيل. لا تحذفه إن أردت الاحتفاظ ببياناتك. مسار البيانات قابل للتغيير بمتغير `TEACHER_DATA_DIR`. إعداد Docker مرفق؛ تحقق من بناء الصورة على جهازك قبل النشر.

## الميزات

- مكتبة PDF مع حد 40 ميغابايت و400 صفحة للملف.
- استخراج النص وصور الأجزاء بدقة 200 DPI مع رقم صفحة PDF وإحداثيات القص.
- اكتشاف Module وLesson وSection وA–F بشكل محافظ. الصفحات غير الواضحة ومتعددة الأعمدة تبقى كاملة مع تنبيه مراجعة. راجع القصاصات مع الأصل؛ لا يضمن الاكتشاف فهم هيكل كل كتاب.
- عند عدم العثور على عناوين لا نختلقها: تكون الوحدة `null` والدرس والقسم «غير مصنّف».
- بحث TF-IDF محلي يعرض النص الأصلي ومصدره وصورته، محصور في الأجزاء المتاحة من الدرس الحالي.
- تنقّل متسلسل وحفظ التقدم والملاحظات وتصدير التقدم، مع وضع فاتح/داكن وواجهة RTL.
- تصحيح بمفتاح إجابات محلي وتلميحات ومحاولات متكررة وكشف الحلول. النجاح يتطلب صحة جميع إجابات الجزء. الإكمال بعد كشف الحل يسجل كمراجعة ذاتية.

## استيراد الإجابات

من «مصادر الكتاب» نزّل المنهج والقالب، ثم استورد مفتاح JSON موثوقاً باستخدام معرّفات الأجزاء:

```json
{
  "p1-B": [
    {
      "question": "Where is Lina from?",
      "accepted": ["Baghdad", "from Baghdad", "She is from Baghdad"],
      "hint": "Read the first sentence.",
      "explanation": "Lina is a student from Baghdad."
    }
  ]
}
```

الاستيراد يستبدل المفتاح كاملاً بعد التأكيد. يجب أن تراجع الإجابات بنفسك. المقارنة تتجاهل حالة الأحرف وعلامات الترقيم والمسافات الزائدة؛ الإجابات الحرة الصحيحة غير المسجّلة قد لا تُقبل. عند غياب المفتاح تكون المتابعة مراجعة ذاتية دون علامة نجاح مؤكدة.

## حدود النسخة

لا تتضمن نموذجاً توليدياً أو ترجمة أو تحليل الرسومات أو OCR. البحث يعرض مقتطفات ولا ينتج شرحاً جديداً. استخدم كلمات إنجليزية من النص؛ لا يحل البحث ضمائر أسئلة المتابعة من سجل المحادثة. عبارة `This information is not in the book.` تعني أن البحث لم يجد مقطعاً ذا صلة في نطاقه، ولا تثبت غياب المعلومة من الكتاب كله.

الصفحات الممسوحة قابلة للعرض لكن البحث يحتاج طبقة نص من أداة OCR محلية. النموذج التوليدي المحلي خيار مستقبلي، وليس اعتماداً مخفياً أو نموذجاً جرى تنزيله.

يحفظ `data/books/<book-id>/` الكتاب والنصوص والصور والمنهج والمصادر و`progress.json` والإجابات. انسخ `data` احتياطياً لاستعادة المكتبة كاملة. ملف تقدم تالف يوقف القراءة دون الكتابة فوقه. المحادثة مؤقتة للجلسة، والملاحظات دائمة. لا تدعم النسخة الكتابة المتزامنة لعدة مستخدمين.
